01 / GET STARTEDStart Here

Almost every Bannerlord mod, ours and other people's, expects these to be installed. Install them first, in this order.

BLSELoader

Bannerlord Software Extender. You launch the game through it. It adds an extended launcher with load-order sorting and compatibility checks, and catches the exceptions that become crash reports.

 HarmonyPatching

The patching library nearly every mod uses to change how the game behaves. Installing it once keeps mods from shipping their own clashing copies.

 ButterLibAPI

Common functions and an API other mods build on, plus the component that generates a crash report when something goes wrong.

 UIExtenderExUI

Lets several mods change the same game screen without fighting each other over it.

 MCMSettings

Mod Configuration Menu. If a mod has an in-game settings screen, it almost certainly uses MCM to draw it. Needs the three above.
Load Order BLSE → Harmony → ButterLib → UIExtenderEx → MCM → Your Mods

BLSE extends SubModule.xml with DependedModuleMetadatas: load before or after, version ranges, optional, incompatible. The launcher sorts your load order from it.

03 / CONNECTServices

Community infrastructure we run and pay for. Live availability is on the status page.

Crash Report Viewer crash-report-viewer.butr.link

Visualises a crash report generated by ButterLib, so you can see what failed instead of reading the raw report.

 Crash Report Dashboard sitenexusmods.butr.link

Link your mods, see every crash report that involves them, and triage them. Sign in with Nexus Mods or Steam.

 Translations translate.butr.link

Translate Bannerlord mods into your language in the browser. No files to edit, nothing to install. BUTR mods are already there, and any mod author can add their own.

 Mod List modlist.butr.link

Stores your mod list so it can be pulled back by a link, or by apps like Discord bots.

 Download Badges nmstats.butr.link

shields.io endpoints for Nexus Mods download and endorsement counts. Drop a live badge straight into your mod's README.

 Service Status status.butr.link

Live uptime for everything above. Check here first if something looks broken.

04 / CREATEMake a Mod

Start from the template: it produces a mod that builds and loads in one command. Use the libraries below as your mod needs them.

Bannerlord.Module.Template★ 82 A dotnet new template that produces a module that builds and loads in one command. Bannerlord.ReferenceAssemblies★ 10 Compile against any game version from e1.1.0 without owning that build. BUTR.Harmony.Analyzer★ 9 Catches a broken Harmony patch target at compile time instead of at runtime. Bannerlord.ModuleManager★ 9 The dependency and load-order resolver, as both C# and JS/TS libraries. Bannerlord.XmlSchemas★ 4 XSD schemas for the game's XML, so your editor autocompletes and validates it. Bannerlord.BuildResources★ 7 BUTR MSBuild tooling that fills in SubModule.xml and assembles the module folder. Requires BUTR build properties such as ModuleName, GameVersion and GameFolder. Bannerlord.ModuleLoader★ 3 Package implementations for different game versions inside one module. Generates a loader that selects the implementation to load. Harmony.Extensions★ 6 Additional Harmony helpers, including AccessTools2, SymbolExtensions2 and Traverse2.
